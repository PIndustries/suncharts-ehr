SunCharts EHR is an independent, self-hosted clinical workspace built with Rust and PostgreSQL.

This developer preview includes patient records, scheduling, encounter documentation, clinical lists, local orders and results, insurance and billing, claims and remittance workflows, OAuth2 connectivity, and an initial FHIR API.

The engine and web interface are licensed under AGPL-3.0-only. The API specification is Apache-2.0.

Use synthetic data only. This preview is under active development and is not designated for clinical production.

See the repository README for setup, CONTRIBUTING.md for development, and SECURITY.md for private vulnerability reporting.
